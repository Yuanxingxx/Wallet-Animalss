# 钱包小动物 · 消费类型趣味问卷

这是按开发方案实现的首版：开始页 → 8 题 → 四类结果，可以返回修改、处理平分、重新测试。马卡龙色手机界面；无需后台、登录、安装第三方依赖或配置服务器。

## 先在电脑上体验

双击打开 `preview/index.html`，即可在浏览器中体验完整问卷。手机浏览器预览需将整个项目置于同一静态服务中，不能只复制 HTML 文件。

这是网页预览版，用于确认内容和交互，不代表小红书原生工具已编译通过，也不是已公开发布的小程序。

## 导入小红书原生版

1. 使用小红书官方开发者工具，为已获准的主体和类目创建普通小程序项目。
2. 导入 `miniprogram` 文件夹，填写你自己的小红书 AppID。`project.config.json` 中 `appid` 留空，未写入虚构账号。若工具要求先创建空项目，保留工具生成的项目配置，把本目录的 `app.js`、`app.json`、`app.css`、`pages`、`data`、`utils` 复制进去即可。
3. 编译后，从开始页检查选择、下一题、上一题、修改、结果、重新测试。分别测试全 A、全 B、全 C、全 D，以及 AABBCCDD 的平分情况。
4. 使用官方真机预览检查 Android/iOS 的布局、返回键及滚动。emoji 插画由设备字体显示，外观可能略有差异。
5. 完成开发方案中的 10–20 人试用、主体/类目/隐私/备案核验，再按平台流程提审发布。

本项目是普通多页原生小程序，文件为 `.xhsml`、`.css`、`.js`、`.json`，调用 `xhs` 页面导航接口。请勿直接作为微信项目或单页小组件项目导入。若账号实际开放的是其他形态，需要按相应平台规范另行适配。

当前交付未使用真实 AppID，未在官方开发者工具或小红书真机中编译、提审、发布。已验证范围见 `验证记录.md`。

## 内容与数据处理

- 问卷和结果沿用同目录外的开发方案，四类为悦己兔兔、精打细算松鼠、品质慢选猫、灵感探索狐。
- 每题选项 A/B/C/D 对应一类，加 1 分。最高分获选；并列时从 Q8 向 Q1 找到的第一个并列候选为展示类型，同时明确展示并列说明。
- 不计算准确率、消费能力等级或风险标签；结果为原创娱乐内容，非标准心理量表或专业评估。
- 只用运行内存保存本次答案，不上传、不持久保存；网页刷新或小程序进程结束后丢失。短暂切后台可能保留本次进度。
- 无远程字体、图片、接口、广告、统计 SDK、支付、云端或第三方运行依赖。平台自身的数据处理以平台规则为准。
- 没有强制分享、关注或评论；用户自行截图即可。

## 修改与验证

修改题目和结果：编辑 `miniprogram/data/content.js`；原生版和网页预览共用这份数据以及计分函数。

界面样式：原生版在 `miniprogram/app.css`，网页预览在 `preview/style.css`，调整视觉时两处同步。原生模板和网页结构分别实现，平台导航需在官方工具中最终核验。

如电脑已有 Node.js，在项目根目录运行：

```powershell
node tests/verify.cjs
```

这会检查计分规则、非法输入、全部 65,536 种答案组合，以及模拟环境下的原生页面操作与导航失败恢复；它不能代替官方编译和真机检查。
